# Система учета туристических путевок (Лабораторная работа №2)

## Описание проекта
Данный проект разработан в рамках дисциплины по документированию программных проектов. Система предназначена для автоматизации учета туристических путевок, управления клиентами, турами и бронированиями.

## Структура проекта
- `src/` — папка с исходным кодом программы.
- `docs/diagrams/` — папка для схем и диаграмм проекта (включая диаграмму вариантов использования / Use Case).

## Основной функционал
- Учет доступных туристических направлений и путевок.
- Регистрация и ведение базы данных клиентов.
- Оформление бронирования путевок.
